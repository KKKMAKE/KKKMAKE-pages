## 第一节：怎么打开这个网站

在你的文件夹里找到这个文件：

    index.html

**用鼠标双击它**，它会自动在你的浏览器里打开（推荐用 Chrome 或者 Edge）。

就这么简单。不需要安装任何东西。

小提示：你可以右键点击 `index.html`，选「打开方式」，挑一个你喜欢的浏览器，
再点一下「始终使用此方式打开」，以后双击就固定用它了。

## 第二节：这个网站里都有什么

从上往下，一共九个部分：

    1. 顶部导航栏      网站名字 + 菜单，手机上会自动变成三条杠的菜单
    2. 首屏大标题      打开网站第一眼看到的那句话
    3. 数据展示        四个数字，滚动到那里会自动往上跳
    4. 关于我          一段自我介绍 + 一张人物插画
    5. 技能            六个带进度条的技能
    6. 作品            六张作品卡片，可以按分类筛选
    7. 服务            三张「我能帮你做什么」的卡片
    8. 联系方式        左边联系方式，右边一个留言表单
    9. 页脚            版权、社交图标、回到顶部按钮

所有内容都是**示例内容**。里面的"林知远"是我虚构的一个人，
你可以把所有文字都换成你自己的。

## 第三节：怎么改文字（最重要的一节）

### 3.1 先认识一下你要打开的文件

用**记事本**（Windows 自带）打开 `index.html`：

    右键 index.html → 打开方式 → 记事本

记事本确实不好看，但够用。如果你愿意装一个更好用的，
推荐搜一下「VS Code」，免费，装完直接把文件拖进去就行。

### 3.2 用「去找暗号」的方式找到要改的地方

我在文件里埋了很多这样的注释：

    <!-- 第 4 板块：关于我 -->

注释是给**你自己看**的提示，浏览器会自动忽略它，不会影响网站显示。

你只需要在文件里找这一类暗号，然后改它下面的文字即可。

### 3.3 九个暗号，对应九个板块

在记事本里按 `Ctrl + F`，输入下面任意一行，回车，就能跳到那个位置：

    第 1 板块：顶部导航栏
    第 2 板块：Hero 首屏
    第 3 板块：数据统计
    第 4 板块：关于我
    第 5 板块：技能
    第 6 板块：作品 / 项目展示
    第 7 板块：服务 / 能做什么
    第 8 板块：联系方式
    第 9 板块：页脚

### 3.4 改文字时最重要的一条规矩

**只改文字，不要动两边尖括号里的东西。**

举个例子，这一行：

    <h3 class="work-title">禾光科技官网改版</h3>

你可以把它改成：

    <h3 class="work-title">我做的第一个网站</h3>

但是**不能**改成（注意末尾少了东西）：

    <h3 class="work-title">我做的第一个网站     ← 这里故意少了 </h3>，别学

尖括号 `<` 和 `>` 是网页的骨架，动坏了页面就会乱掉。

**安全提示：每次改之前，先把 index.html 复制一份改名成「备份.html」。
改坏了就把备份改回来。**

### 3.5 几处你最可能想改的地方

改网站名字（出现在左上角和页脚）：

    搜索：brand-name
    找到：<span class="brand-name">林知远</span>
    把「林知远」改成你的名字

改首屏那句大标题：

    搜索：第 2 板块
    找到：<h1 class="hero-title"> 下面那两行，改成你想说的话

改四个数字：

    搜索：data-count
    找到：<span class="stat-num" data-count="42" ...>
    把 42 改成你要的数字

改技能百分比（改两处，要一致）：

    搜索：skill-level-num
    找到：<span class="skill-level-num">92%</span>
    改它

再搜索：data-level

    找到：<span class="skill-fill" data-level="92"></span>
    改成和上面一样的数字

改联系方式：

    搜索：第 8 板块
    里面的邮箱、微信、城市、工作时间都可以直接改

### 3.6 想多加一个作品卡片怎么办

搜索 `作品 1`，你会看到这样一整块，从 `<!-- 作品 1 -->` 开始，
到下一个 `<!-- 作品 2 -->` 之前结束。

把这一整块（从 `<article` 到 `</article>`）**复制一份，粘贴到它下面**，
然后改里面的文字就行了。复制几份就有几个作品。

同理要注意：卡片上有一行 `<span class="work-tag">网页</span>`
和一个属性 `data-category="web"`，这两个决定了它属于哪个分类。
目前支持的三个值是：

    web      网页
    design   设计
    other    其他

## 第四节：怎么换图片

现在网站里所有的插画、头像、作品封面，都是**用代码画出来的图形**，
不是图片文件。这样做的好处是永远不会失效、永远不会变模糊。

### 4.1 只想改画的颜色

比如作品封面，搜索 `作品 1`，找到 `<svg` 开头到 `</svg>` 结束那一大段，
里面会有这样的颜色代码：

    stop-color="#4F46E5"

把 `#4F46E5` 换成你想要的颜色（第五节 5.1 里有常用颜色代码表），保存后刷新页面。

### 4.2 想换成自己的真实照片

以头像为例：

第一步，把你的照片放进 `assets` 文件夹里，起个简单的英文名，比如 `me.jpg`。
建议照片用竖版，比如 800 x 900 像素左右，别的尺寸也能用，只是可能被裁。

第二步，搜索 `portrait-svg`，把以 `<svg` 开头到 `</svg>` 结尾的**那一整段**删掉，
换成这一行：

    <img src="assets/me.jpg" alt="我的照片" />

注意：路径要写成 `assets/me.jpg`，前面**不要**加斜杠。

第三步，保存，刷新浏览器。

图片会自动带上圆角、自动缩放到卡片宽度，不用你管。

### 4.3 想给作品卡片也换成真实截图

做法和上面一样：

    1. 把图片放进 assets 文件夹，例如 assets/work1.jpg
    2. 搜索 作品 1，在它下面找到 <div class="work-cover">，
       把里面的 <svg>...</svg> 整段删掉
    3. 换成这一行：
       <img src="assets/work1.jpg" alt="项目截图" />
    4. 保存，刷新

图片会被自动裁成统一的封面比例（大概 20:13，偏横版）。
想要效果最好，准备横版的图，宽度 800 像素左右就够了，别放几兆的大图。

## 第五节：怎么改颜色和字体

打开 `assets` 文件夹里的 `style.css`，**文件最上面那一段**就是给你留的调整区。

那里的每一行都有一个注释说明它是干嘛的。你只需要改等号右边的东西。

### 5.1 换整套颜色（最省事的一步）

找到这一行：

    --color-accent: #4F46E5;

这就是网站的「强调色」，按钮、图标、重点文字都用它。

把 `#4F46E5` 换成下面任意一个试试：

    #4F46E5    靛蓝（现在的样子，偏冷静、专业）
    #D97706    琥珀（偏温暖、有活力）
    #0F766E    墨绿（偏沉稳、有质感）
    #B91C1C    砖红（偏醒目、有冲击力）
    #7C3AED    紫色（偏创意、年轻）

改完保存，刷新浏览器，整个网站的颜色就跟着变了。

注意：记得连下面这行一起改，它上面那个颜色浅一点的版本：

    --color-accent-soft: #EEF2FF;

    配 #4F46E5 用 #EEF2FF
    配 #D97706 用 #FFFBEB
    配 #0F766E 用 #F0FDFA
    配 #B91C1C 用 #FEF2F2
    配 #7C3AED 用 #F5F3FF

### 5.2 改背景颜色

    --color-bg: #FAFAF9;      这是页面背景，现在是暖白色
    --color-surface: #FFFFFF; 这是卡片的底色，现在是纯白

### 5.3 改文字颜色

    --color-text: #1C1917;       大标题和正文的黑
    --color-text-soft: #57534E;  次要文字的灰

### 5.4 想在手机上把自己居中/字号改一改

先跳过这节。等你改顺手了再说，这部分改动风险稍大。

## 第六节：怎么让它真的能收到别人的留言

**现在这个表单是假的。**

别人填了、点了发送，会看到「发送成功」，但实际上**什么也没发生**，
你收不到任何东西。这是故意的，因为收邮件需要服务器。

想真的收到留言，最简单的办法（不用写代码、不用花钱）：

    1. 打开这个网站：https://formspree.io
    2. 用邮箱注册一个免费账号（免费版每月 50 条留言够用）
    3. 创建一个表单，它会给你一串网址，长这样：
       https://formspree.io/f/abcd1234
    4. 回到 index.html，搜索 第 8 板块，再往下找到这一行：
       <form class="contact-form" id="contactForm" novalidate>
    5. 把它整行替换成（用你自己的那串地址）：
       <form class="contact-form" id="contactForm" action="https://formspree.io/f/abcd1234" method="POST">
    6. 保存，上传到网上（看第七节），然后自己填一次试试

就这样，别的什么都不用改。

因为网站里的脚本会自动识别：只要 `<form>` 上有 action，
它就会把内容真的发出去；没有 action 时，就只是演示一下。

如果你哪天想改回演示模式，把 action="..." 这一小段删掉就行。

看不懂也没关系。这一步可以先放着，等你把网站内容改满意了再做。

## 第七节：怎么免费放到网上

目标：让别人输入一个网址就能看到你的网站，并且不花一分钱。

这里推荐 **GitHub Pages**，免费、稳定、够用。

下面给的是**完全不用敲命令**的做法，全程在网页上操作。

### 7.0 开始之前

你需要：一个邮箱。就这么多。

### 7.1 注册 GitHub

    1. 打开 https://github.com
    2. 点右上角 Sign up，用邮箱注册
    3. 邮箱里会收到一封验证邮件，点里面的链接完成验证

GitHub 是全世界程序员放代码的地方，但你完全不用懂代码也能用它放网站。

### 7.2 创建一个新的仓库

    1. 登录后，点页面右上角的加号图标，选 New repository
    2. Repository name 填：你的名字-pages
       例如：linzhiyuan-pages
    3. 选 Public（公开，必须选这个，否则免费版看不到）
    4. 勾上 Add a README file
    5. 点最下面绿色的 Create repository

### 7.3 上传你的网站文件

    1. 进入刚创建的仓库页面
    2. 点中间的 Add file 按钮，选 Upload files
    3. 用鼠标把你的三个东西拖进去：
         index.html
         assets 文件夹（整个文件夹一起拖）
         README.md（可以不传）
       注意：assets 文件夹里的内容要保持原样，不要只拖里面的 css 和 js
    4. 页面下方点绿色的 Commit changes

稍微等几秒，你的文件就上传好了。

### 7.4 打开 Pages 开关

    1. 在仓库页面顶部，点 Settings（如果看不到，先把浏览器窗口拉宽）
    2. 左侧菜单里点 Pages
    3. 在 Source 那一栏，选 Deploy from a branch
    4. 下面的 Branch 选 main，右边的文件夹选 / (root)
    5. 点 Save

### 7.5 等两分钟，然后访问

等大约一到两分钟，刷新 Settings → Pages 页面，
上方会显示一行网址，类似：

    https://你的用户名.github.io/linzhiyuan-pages/

点开它，你的网站就上线了。

这个网址可以直接发给任何人。

### 7.6 以后想改内容

回到仓库，点进 index.html，点右上角的铅笔图标（Edit），
改完文字，点 Commit changes，等两分钟刷新你的网址即可。

### 7.7 想用自己买的域名

等你走通上面这一步再说，别一次做太多事。
大致流程是：在域名服务商那里加一条 CNAME 记录指向 GitHub，
然后在 Settings → Pages 里填你的域名。到时候可以再查。

## 第八节：常见问题

### 问：我改了文字，刷新后没变化？

按顺序试：

    1. 确认你在记事本里点了「文件 → 保存」
    2. 确认你打开的是改过的那个文件（有时候会改错副本）
    3. 在浏览器里按 Ctrl + F5（强制刷新），
       或者 Ctrl + Shift + R
    4. 还是不行就关掉浏览器标签，重新双击 index.html

浏览器的缓存经常骗人，Ctrl + F5 是最好用的一招。

### 问：页面突然乱了，或者有大片空白？

大概率是不小心删了某个 `<` 或 `>` 或者 `</div>`。

    1. 先把你刚才改的那一步撤回
    2. 如果撤不回来，就删掉当前文件，把之前备份的那份改回来
    3. 再一点点试着改，改一次保存一次，别一次改太多

### 问：为什么推荐我每次改之前都备份？

因为网页就是这样，少一个符号就可能整页错位。备份能让你随时重来，
成本最低，效果最好。

### 问：手机上怎么预览？

在自己家里最简单的方法：

    1. 电脑上打开文件所在的文件夹
    2. 确认你的手机和电脑连的是同一个 WiFi
    3. 具体传法看你的习惯，可以用微信文件传输助手把 index.html 发到手机，
       但手机不一定打得开（assets 里的样式会丢）

更靠谱的办法：直接按第七节上线到网上，然后用手机浏览器打开那个网址。
这样看到的才是真实效果，也方便发给别人。

### 问：为什么我用微信发给朋友，他打不开？

因为 index.html 依赖 assets 里的样式和脚本，只发一个文件过去会丢样式，
页面看起来会是光秃秃的黑白文字。

正确做法：把整个 site 文件夹压缩成一个 zip 包再发，或者按第七节上线。

### 问：为什么我看到的插画是画出来的，不是照片？

因为要保证「断网也能打开」「传文件不会失效」。
想换成真实照片，看第四节。

### 问：页脚那几个社交图标点了没反应？

它们是占位的，现在都指向页面顶部。

想改成真的，搜索 `footer-social`，把里面的 `href="#hero"` 换成你的链接，
例如：

    href="https://github.com/你的用户名"

### 问：网站要花钱维护吗？

一分钱都不用。GitHub Pages 免费。

唯一花钱的是你自己买的域名（一年几十块），但那个也不用先买，
用 github.io 的免费网址就够用了。

### 问：我不知道起什么网站名字？

先用你的真名，或者「名字 + 在做的事」。
例如「林知远 · 产品设计师」。
最重要的不是名字好听，是让人一眼知道你是谁、在做什么。

## 第九节：文件说明

整个网站只有四个文件：

    site/
    ├── index.html          网站的全部内容和文字
    ├── assets/
    │   ├── style.css       网站的所有外观（颜色、字体、间距）
    │   ├── script.js       网站的交互（菜单、动画、表单提示）
    └── README.md           你现在正在看的这份说明

分工很简单：

    想改文字  →  改 index.html
    想改外观  →  改 assets/style.css
    想改行为  →  改 assets/script.js（一般不用改，可以先忽略）

### 这个网站没有用到的东西

为了让你打开就能用，这个文件刻意**没有**使用：

    - 不需要 npm，不需要安装任何包
    - 不需要联网，不引用任何外部图片、字体、脚本
    - 不需要本地服务器，双击就能看
    - 不用 React、Vue 这类框架，是纯手写的代码

好处是：简单、稳定、十年后还能打开。
代价是：内容都写死在 HTML 里，加一篇文章要手动复制一段代码。

对你现在的阶段来说，这个交换是划算的。

第一次做网站，最容易犯的错不是改错，而是**不敢动手**。

先试着把名字改成你自己的，保存，刷新 —— 你会立刻明白它是怎么回事。
